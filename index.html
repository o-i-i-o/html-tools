html-tools

前端工具箱

纯静态工具集。

  • 01 日期计算器 Date-Calculator/ 计算两个日期的差值，推算若干天 / 工作日后的日期，支持农历。
  • 02 Crontab 执行时间计算器 crontab-calculator/ 根据 cron 表达式推算未来执行时间，支持图形化生成表达式。
  • 03 随机密码生成工具 password-generator/dist/ 按长度与字符集生成随机密码，并评估密码强度。
  • 04 子网计算器 subnet-calculator/ IPv4 / IPv6 子网划分与掩码计算，支持中英文切换。
GPLv3 · 纯 HTML / CSS / JS，无构建依赖
